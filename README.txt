YALLAVULA VENKAREDDY - PORTFOLIO

HOW TO RUN
1. Extract this folder.
2. Open index.html in a browser.
3. For best results, use a current version of Chrome, Edge, or Firefox.

CUSTOMIZE
- Edit text, project details, education, and contact details in index.html.
- Change colors and layout in style.css.
- Change the animated role list and effects in script.js.

NOTES
- The portfolio is responsive and uses HTML, CSS, and vanilla JavaScript.
- Google Fonts are loaded online; the page still works if they are unavailable.
- Verify the LinkedIn profile URL and all contact details before publishing.
